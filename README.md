# Net4Fun Hub

PWA instalável para clientes da Net4Fun, preparada para integração com ggLeap.

- Uso diário: consulta de PCs/consoles por ordem de chegada.
- Corujão: reserva de PC somente dentro do evento.
- PWA: instalação pelo navegador em Android e iPhone.
- Backend Node sem dependências externas.

## Variáveis opcionais para ggLeap

`GGLEAP_PUBLIC_API_BASE`, `GGLEAP_PUBLIC_API_TOKEN`, `GGLEAP_MACHINES_PATH`, `GGLEAP_CENTER_UUID`.
